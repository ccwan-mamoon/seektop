# SeekTop 1.0.5 · AI 分析、汇率与剩余价值计算器

- **AI 分析**：支持流式 Markdown、追问和补充信息；可选只分析楼主（含后续回复）或全楼层，支持各板块独立提示词。
- **汇率设置**：缓存 15 种常用币种参考汇率，展示日期和来源；支持手动修改、保存和恢复自动，手动值不被后台更新覆盖。
- **本地计算器**：回复、发帖下方增加入口，支持型号、日历选择、分钟精度、月付至三年、自定义周期，以及 Push／中介费分摊。汇率报价保留两位小数，日元和韩元按每 100 单位报价。
- **直接导入**：计算结果一键插入带图标的 Markdown 表格，保留周围草稿，不经过剪贴板、不自动发布；计算器不调用 AI，无需 API Key。
- **外部链接**：首次启动询问是否接管。完成 Windows 默认应用关联后，Telegram 等外部应用的 NodeSeek 帖子进入 SeekTop，其他网址沿用原浏览器。
- **插件预留**：保留官方签名、安装和独立更新能力；网速、连通性和 iperf3 三个插件继续从市场隐藏。

提供 Windows x64 EXE 安装包、ZIP 便携包、对应源码及 SHA-256 校验文件。稳定版用户可通过客户端检查更新；安装和升级保留现有用户资料。

AI 效果取决于配置的服务商与模型；参考汇率并非实际支付汇率。Android、iOS 代码保留，本次发布目标为 Windows x64。
