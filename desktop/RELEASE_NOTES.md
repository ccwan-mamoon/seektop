# SeekTop 1.0.9 · 首次接管提示与 AI 追问测试版

- 首次使用询问是否接管外部链接；暂不接管也会记住选择，已有配置不重复提示。启用后仍需在 Windows 确认默认关联。
- AI 分析新增追问输入框，可补充到期时间、费用等信息并继续分析。
- 「重新分析」改为范围菜单：只分析楼主／全楼层分析。首次仍自动分析楼主，选择范围会刷新对应数据。
- 全楼层读取所有分页，展示页数、可见回复数和屏蔽排除数；不会改变原帖阅读位置。
- 追问沿用最近一次范围快照，切换范围继续保留本次补充信息。关闭分析窗口后清除会话。
- 全楼层上限 100 页、约 12 万字符。读取失败、分页变化、账号变化或超过限额时不会提交不完整内容。

本地测试版，未发布客户端稳定更新。真实 AI 效果需要使用你的 API 配置验收。
