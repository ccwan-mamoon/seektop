# SeekTop 1.0.6 · 原生邮箱与图片粘贴上传

- 新增 Seek.li 原生邮箱：邮箱切换、读写信、Markdown 编辑预览、抄送与密送、邮件搜索、星标、标签、移动和删除。
- 接入邮箱、联系人、文件夹、标签、收信规则和签名管理，支持原文导出、附件下载与独立上传、配额查询。
- 自动收信默认每分钟，可选 30 秒、1/2/5/10/30 分钟、1 小时；设置重启保留，切换目录立即更新。
- 优化邮箱未读徽标、日期、滚动条及界面配色，增加官方 API Key 配置页入口。
- 修复邮箱空列表、详情响应兼容、发件邮箱下拉尺寸错误和托盘菜单中文显示。
- 发帖与回复支持粘贴图片上传到保存的图床；多个图床首次选择，设置中可调整优先级。

- **发信修订**：修复收件人、抄送和密送字段与实际服务端不兼容导致的 BAD_REQUEST；保留服务端具体错误提示。本次已重新构建 1.0.6 发布包。

提供 Windows x64 安装包、便携包、对应源码及 SHA-256 校验文件。升级保留用户资料。

邮箱需自行配置 Seek.li API Key，并授权所需权限；定时收信采用轮询，非实时推送。公开 API 未定义的发信附件、定时发送、邮箱分租和锁定功能未接入。Android、iOS 代码保留，本次发布目标为 Windows x64。
