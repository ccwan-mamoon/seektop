# SeekTop 1.0.4 · 寻桌

Windows x64 正式版，提供 EXE 安装包和 ZIP 便携包，沿用 Compose + Electron。

- 帖子刷新获取最新末页并定位到底部；无新增回复时提示，失败保留阅读位置。
- 追踪回复提醒直接定位首个新增楼层，兼容旧提醒记录。
- 切换标签保留搜索、会话及内部页面；重复点击当前标签返回根页面，首页仍返回综合列表并刷新。
- 私信按会话变化提醒，通知发送失败排队重试，已成功的条目不重复发送。
- 启动先检查签到：尚未设置时首次弹窗选择并保存，以后按保存方式执行；设置可切换随机或固定五鸡腿。已签到不重复提交，检查失败不盲目签到。
- 关闭窗口可选择退出、最小化到系统托盘或取消；托盘支持打开和退出，打开时恢复原页面，原生通知仍按目标跳转。
- 保留重复点击当前帖子关闭详情的行为。

安装版与便携版均支持应用内下载 ZIP 更新并重启生效。登录、偏好和提醒保存在 %LOCALAPPDATA%/SeekTop；卸载安装版保留用户数据。

提供对应源码与 SHA256SUMS.txt，安装包暂未配置代码签名证书。插件目前仍为接口预留，尚不支持安装或运行。

JVM 回归、运行时、浏览器桥接与安装卸载检查通过；关闭选择框已通过隔离窗口实机检查。真实账号签到、登录验证及托盘操作仍请按实际环境验收。
