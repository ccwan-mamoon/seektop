# SeekTop 0.3.0 · 寻桌 — 现代桌面界面预览版

基于 [Nodyssey](https://github.com/5151561/nodyssey) 二次开发，采用 GPL-3.0，保留上游版权。与 NodeSeek 官方及上游维护者无隶属或背书关系。

下载 `SeekTop-0.3.0-windows-x64.zip`，完整解压后运行 `SeekTop.exe`。无需额外安装 Java、Node.js 或 Python。

## 本版改动

- 深色侧栏、紧凑品牌区、方圆角搜索框和工具栏，阅读区使用独立面板与更清楚的留白。
- 帖子列表增加头像、鼠标悬停、选中反馈和更清楚的标题与元信息层次。
- 修复板块栏鼠标操作：竖向滚轮映射为横向浏览，支持按住鼠标左键拖动。
- 板块栏增加左右滚动箭头与全部板块菜单，选中板块自动进入可见区域。
- 保留分栏阅读、右键菜单、固定操作栏和桌面快捷键。

鼠标滚轮和拖动用于浏览板块栏，点击板块进入该板块；滚动不会意外切换当前板块。

## 限制

这是现代桌面界面预览版，尚未对所有账号功能逐项完成 Windows 实机验证。登录使用“改用网页登录”，完成后点击登录窗口“完成并返回应用”。自动更新、系统推送、头像更换、图片保存、系统分享、退出后的后台下载及网络计费限制尚未适配。

同版本源码和 SHA-256 校验文件随发布提供。完整来源及许可证说明见 `NOTICE.md`。
