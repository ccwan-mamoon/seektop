# SeekTop 0.1.0 · 寻桌 — Windows 移植预览版

基于 [Nodyssey](https://github.com/5151561/nodyssey) 二次开发，采用 GPL-3.0，保留上游版权。与 NodeSeek 官方及上游维护者无隶属或背书关系。

## 下载

下载 `SeekTop-0.1.0-windows-x64.zip`，完整解压后运行 `SeekTop.exe`。无需额外安装 Java、Node.js 或 Python。请保留完整目录。

## 本版内容

- 复用原 Compose 界面、导航、富文本和共享业务逻辑。
- Windows 宽屏双栏浏览、帖子详情、评论和头像显示。
- JVM Room、DataStore、桌面文件选择和文本导入导出适配。
- Chromium 登录窗口与原请求链共享会话。

## 验证与限制

Windows 应用已实际启动并验证首页、真实帖子、正文、评论和头像。381 项 JVM 测试及格式检查通过，桥接鉴权和 Cookie 域隔离检查通过。

这是预览版本。登录使用“改用网页登录”，完成后点击登录窗口“完成并返回应用”。账号登录后的互动与资金操作未实际提交验证。自动更新、系统推送、头像更换、图片保存、系统分享、退出后的后台下载及 Wi-Fi 计费限制尚未适配。

同版本源码和 SHA-256 校验文件随发布提供。完整来源及许可证说明见仓库 `NOTICE.md`。
