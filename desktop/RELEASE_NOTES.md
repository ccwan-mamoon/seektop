# SeekTop 1.0.3 · 寻桌

Windows x64 正式版，沿用 Compose + Electron。

- 提供 EXE 安装包和 ZIP 便携包，均包含完整 Java 与浏览器运行时，无需另装 Java、Node.js 或 Python。
- 通知页分为互动、私信、提醒。关键词命中和追踪新回复保存到本机提醒列表，支持已读并在重启后保留。
- Windows 原生通知点击后打开各自对应的帖子楼层、私信会话或提醒帖子。
- 切换板块、重复点击板块均从第一页刷新；首页和左上角图标返回综合列表并刷新，保留排序。
- 修复设置页返回首页及板块选择请求丢失的问题。
- 预留 Seek.li 邮箱与 NodeImage 插件声明和扩展入口；本版尚不支持安装或运行插件。

首次使用可下载安装包，按当前用户安装并创建快捷方式；便携版请完整解压后运行 SeekTop.exe，保留整个目录。两种形式均支持应用内下载 ZIP 更新并重启生效。

登录、偏好和提醒数据位于 %LOCALAPPDATA%/SeekTop。安装版卸载保留用户数据；卸载信息独立于程序目录，兼容应用内 ZIP 更新。ZIP 更新后 Windows 卸载登记的版本号会在再次运行安装包后刷新。

同时提供对应源码和 SHA256SUMS.txt。安装包尚未配置代码签名证书。

JVM 回归、浏览器桥接、精简运行时、安装卸载与 ZIP 更新目录替换检查通过。真实账号登录、两步验证和站点写入操作仍需按实际账号验收。
