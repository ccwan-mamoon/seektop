# SeekTop 1.0.2 · 寻桌

Windows x64 正式版，沿用 Compose + Electron，主界面保持不变。

- 按需打包 Java 运行时，减少不必要的开发模块。
- 修复游客访问我的主题帖、评论、收藏、关注等页面时误报解析错误，改为登录提示。
- 会话变化时释放个人页面旧状态，保留公开阅读状态，阻止旧账号资料响应进入新会话。
- 先显示窗口，再异步初始化浏览器、代理和设置；启动失败可重试或退出。
- 区分登录、人机验证、权限和服务器错误，改善启动资源清理。

提供包含 SeekTop.exe 的完整 ZIP 便携包、对应源码和 SHA-256 校验文件。完整解压后运行，保留整个目录。

423 项 JVM 测试及正常、异常启动检查通过。真实账号登录、两步验证和切换仍需按实际账号验收。
