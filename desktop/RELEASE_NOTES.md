# SeekTop 1.0.6 · AI 分析测试版

- 帖子顶部新增 AI 分析入口，发送标题、主楼正文及手动勾选的图片链接，不包含评论或论坛 Cookie。
- 支持多个 OpenAI 兼容服务商，自定义 Base URL、模型、图片能力及默认服务商。API Key 通过 Windows safeStorage 加密保存。
- 设置可配置通用提示词和各板块提示词；分析前可临时调整，支持流式结果、停止、复制和继续追问。
- 帖子 AI 分析作为独立官方签名模板插件安装；模板不执行程序、不接触密钥。需要新版客户端提供宿主能力。
- 交易分析可提取估值字段；经用户核对后，本地定点计算剩余价值和溢价，明确周期、日期和币种，不推测缺失价格、不换汇。
- 三个网络工具继续从市场隐藏。新 AI 市场索引与旧客户端隔离，旧版不会收到无法识别的模板运行时。

已通过 JVM 回归、模拟接口 SSE/UTF-8、取消与端点隔离，以及真实 Windows 加密存储、重启恢复、Cookie 隔离和本地流式接口测试。未使用真实付费模型或个人 API Key 验证推理质量，需自行配置服务商测试。客户端稳定版仍是 1.0.4，本地 1.0.6 为测试构建。
