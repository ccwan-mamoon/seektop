# SeekTop 0.4.0 · 寻桌 — 开发预览版（尚未发布）

基于 [Nodyssey](https://github.com/5151561/nodyssey) 二次开发，采用 GPL-3.0，保留上游版权。与 NodeSeek 官方及上游维护者无隶属或背书关系。

本次仅同步源码，未创建 0.4.0 Release。下列内容为未来构建的预览说明。

## 本版改动

- 原生账号密码及两步验证码表单；人机验证在应用自带窗口内完成。
- 安全验证结果与登录请求共享 Chromium 会话；支持取消与过期处理。
- 登录完成和页面清理时清空密码；额外安全检查返回后保留表单输入。
- 左侧常驻板块列表，支持展开、收起、滚轮浏览和点击切换。
- 首页刷新回当前板块第 1 页顶部，保留排序；详情刷新回第 1 页正文开头。

## 验证范围

本地 UI/桌面 JVM 回归、格式检查和 Windows app-image 构建已通过。验证窗口的来源限制、共享会话、结果回传与取消清理已用虚拟数据验证；公开首页读取返回 HTTP 200。

真实账号、真实人机验证及登录后的写入操作仍待使用者验收。自动更新、系统推送、头像更换、图片保存、系统分享及后台任务等限制继续适用。来源与许可见 `NOTICE.md`。
