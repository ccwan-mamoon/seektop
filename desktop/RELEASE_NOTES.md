# SeekTop 1.0.8 · 原生链接与 AI 流式修复测试版

- 修复 DeepSeek V4 Flash 的空回答误判，默认关闭深度思考，回答以 Markdown 流式显示；可在设置开启深度思考。
- AI 增加思考阶段提示和准确错误分类，输出截断时保留已经生成的文字。
- 设置页新增可选的「外部链接接管」，默认关闭，自动记录启用前的默认浏览器。
- 启用后在 Windows 默认应用中将 HTTP 和 HTTPS 设为 SeekTop Links，无需安装浏览器扩展。
- Telegram 等外部应用的 NodeSeek 帖子和用户页可直接打开 SeekTop，其他网址仍用原浏览器；浏览器内部导航保持浏览器行为。
- 支持已运行/托盘唤起，保留页码与数字楼层锚点，并发点击冷启动不会重复启动客户端。
- 关闭后所有链接转回原浏览器；完全恢复关联需在 Windows 中重新选择浏览器。卸载时若仍为默认处理程序，会保留小型转发器避免链接失效。
- 真实默认关联仍需用户手动确认。本地测试版，未发布客户端稳定更新。
