# SeekTop 0.2.0 · 寻桌 — 桌面交互预览版

基于 [Nodyssey](https://github.com/5151561/nodyssey) 二次开发，采用 GPL-3.0，保留上游版权。与 NodeSeek 官方及上游维护者无隶属或背书关系。

下载 `SeekTop-0.2.0-windows-x64.zip`，完整解压后运行 `SeekTop.exe`。无需额外安装 Java、Node.js 或 Python。

## 桌面改造

- 直接进入工作区，取消手机新手向导、下一步和单手模式入口及提示。
- 常驻左侧导航，固定搜索、刷新、发帖工具栏；收藏、历史、设置可直接访问。
- 点击切换板块，紧凑帖子列表、右键复制链接及浏览器打开、可拖动滚动条。
- 宽窗口分栏阅读，切换帖子替换右侧内容；固定翻页和回复底栏。
- 操作面板与回复编辑器使用居中弹窗，取消触摸下拉刷新及页面滑入动画。
- 快捷键：Ctrl+K 搜索，Ctrl+N 发帖，F5 刷新当前帖子或列表，Alt+左箭头返回，Ctrl+逗号设置。
- 最小窗口 1100×700，保留原有账号、缓存、设置和登录会话。

## 限制

这是桌面交互预览版，尚未对所有账号功能逐项完成 Windows 实机验证。登录使用“改用网页登录”，完成后点击登录窗口“完成并返回应用”。自动更新、系统推送、头像更换、图片保存、系统分享、退出后的后台下载及网络计费限制尚未适配。

同版本源码和 SHA-256 校验文件随发布提供。完整来源及许可证说明见 `NOTICE.md`。
