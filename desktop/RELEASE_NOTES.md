# SeekTop 1.0.5 · 插件功能测试版

- 侧栏新增插件中心，提供已安装、插件市场、官方签名包导入、启停、卸载和独立更新。
- 首批网速测试、连通性测试、iperf3 按需下载，每个约 4.6 MB，引擎不捆绑进客户端。
- 工具页沿用 Compose 界面，左侧参数、右侧实时结果，开始/停止固定在底部，切回论坛后保留插件页面状态。
- 市场下载使用独立且不携带 Cookie 的 Chromium 会话，遵守应用代理范围；网络工具使用直连/系统 TUN，不继承论坛登录或应用代理。
- 仅接受 SeekTop 官方 Ed25519 签名的原生工具。它们具有普通 Windows 用户权限，安装时说明；第三方 JS、邮箱和图床扩展仍为预留。
- HTTP 测速有流量上限；连通性区分登录、验证、HTTP 与明确地区限制；iperf3 支持 TCP/UDP、上传/下载/双向与限时服务端，默认监听回环地址。

已验证签名/文件篡改、路径穿越、安装失败保留旧版、降级拒绝、偏好持久化、实际下载安装、NDJSON、取消和端口释放。iperf3 回环实测覆盖 TCP 上传/下载/双向与 UDP 下载。公网测速的实际线路表现和各平台检测结果仍需用户按自己的网络验收。

插件目录已独立发布；当前客户端稳定版仍是 1.0.4，不含插件入口。本地 1.0.5 为待测试构建，尚未发布为客户端稳定更新。插件包内附完整对应源码及许可证。
