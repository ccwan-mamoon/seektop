# SeekTop 1.0.7 · AI 分析交互简化测试版

- 点击帖子「AI 分析」直接开始分析，以 Markdown 展示结果，不需要额外安装插件或再次点开始。
- API 和各板块提示词统一在独立设置页管理，弹窗可直接跳转，返回继续阅读原帖。
- 结果弹窗仅保留设置、复制、停止和重新分析，移除提示词编辑、图片勾选、追问和估值表单。
- 图片分析由设置开关控制，默认关闭；启用后最多发送前 8 张正文图片链接，需要支持图片的模型。
- 沿用现有 API、提示词和 Windows 加密存储，不发送评论或论坛 Cookie。

本地测试构建，未发布为客户端稳定更新。真实模型效果需要自行配置 API 验收。
