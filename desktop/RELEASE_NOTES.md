# SeekTop 1.0.1 · 寻桌

正式版，包含 Windows ZIP 便携版、对应源码及 SHA-256 校验文件。EXE 安装包后续提供。

## 本版更新

- 更新检查和下载跟随应用代理范围设置；“全部流量”覆盖更新，“仅论坛”时更新使用系统网络。
- 修复 GitHub 下载跳转被取消的问题；独立更新会话逐次校验实际请求域名。
- 支持断点续传、取消后保留进度、最多三次自动重试；服务器不支持续传时安全退回完整下载。
- 显示已下载大小、总大小、当前速度和预计剩余时间。
- 下载完成后校验长度与 SHA-256，等待点击“重启并完成升级”。
- 重启不再重复弹出下载确认；准备过程中禁用按钮，防止重复安装提交，失败可重试。

基于 [Nodyssey](https://github.com/5151561/nodyssey) 二次开发，采用 GPL-3.0，保留上游版权。与 NodeSeek 官方及上游维护者无隶属或背书关系。

## 桌面功能

- 可折叠图标菜单、可管理的常用板块、菜单与列表双栏，以及点击帖子后展开的详情栏。
- 列表和详情分隔线支持拖拽调宽，重复点击同一帖子或关闭按钮收起详情。
- 顶栏整合帖子、用户与板块搜索；列表与详情提供独立浮动刷新和页码跳转。
- 原生登录表单、应用内官方人机验证、桌面化的“我的”、通知和设置页面。
- 统一原创图标、实际生效的主题强调色、浅色与深色模式。
- Windows 系统通知：互动、私信、关键词、追踪回复可分别设置检查间隔，支持免打扰、去重和异常退避。

## 一键升级

- 启动检查新版、关于页手动检查和升级提醒。
- 应用内下载、进度显示、取消与 SHA-256 校验；只接收 SeekTop 本仓库的 Windows 包。
- 下载并校验完成后点击重启，自动退出、替换完整程序并重新打开，无需手动解压覆盖。
- 旧目录保留备份；替换或启动进程失败时恢复旧目录。新进程仍运行但未确认启动时保留备份并报告，不强制结束未知状态的进程。
- 登录资料与设置保存在独立数据目录，升级时保留。
- 桌面版本号统一由版本目录提供，发布流程同步生成版本标签和程序包名称。

## 验证范围

本地 JVM 回归覆盖版本筛选、下载完整性、取消、压缩包路径校验、通知调度、偏好保存及升级确认。
独立更新程序使用隔离测试目录执行等待退出、替换重启、失败回滚和无关路径拒绝测试。
未提交真实账号写入操作；完整程序副本已实际完成升级后的自动重启和首帧确认。

首次运行包含更新功能的版本后，未来更高版本发布到 GitHub 才会出现可用升级；不含更新代码的旧版本仍需先切换到这个初始版本。
